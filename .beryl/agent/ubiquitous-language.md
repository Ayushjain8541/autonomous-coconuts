# Shared vocabulary

| Term | Meaning |
| --- | --- |
| Report | One source CSV record describing an encounter estimate |
| Encounter | One event_id with one or more reports |
| Reported Pc | Probability derived from a source report's log10 risk |
| Predicted Pc | Model forecast of later/final source-reported collision probability |
| Severity | Deterministic brief-defined critical/elevated/safe/unknown tier |
| Geometry | Source-relative RTN position/velocity; not a full global orbit |
| Synthetic fixture | Invented interface data explicitly labeled as such |
| Bootstrap | Runnable infrastructure and checks, not completed product inference |
| Handoff | Role's actual revision, setup/check evidence and remaining gaps |
